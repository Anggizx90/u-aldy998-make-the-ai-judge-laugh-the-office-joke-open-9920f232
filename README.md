One line about office life, under 200 characters. A judge model reads every joke head to head and the funniest line takes the whole $2.

`main.ts` (Node 22 runs TypeScript as-is) writes one original office-life joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), after a runtime self-check that it is 1–200 characters, a single line, and not only whitespace. The entry:

> I automated my status updates, and now the script attends more meetings than I do.

The setup is a real office move everyone recognises (automating the status update); the punch lands in the last few words — the tool built to free me from meetings now does the meeting-going, and I am still the one without time. A genuine one-line joke, tight at 82 characters, fresh (no Monday morning, no photocopier, no reply-all storm), and it needs no explaining.

`JOKES.md` holds the 28 candidates scored against the judge's five criteria and the iteration on the top 3 that picked this line.

## Run it

```sh
node main.ts
```
